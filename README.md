# XMage Playgroup — Windows downloads

A private Magic: The Gathering playgroup client built on [XMage](https://github.com/magefree/mage)
and [Phase Out](https://github.com/clifforj/phase-out). Windows 10 or 11, 64-bit. Nothing to install:
Java comes inside the zip.

## Start

1. Open the [latest release](../../releases/latest) and download the `XMage-Playgroup-….zip` file.
2. Right-click the zip, choose **Extract All**, then **Extract**.
3. In the new folder, double-click **Start Playgroup**.
   If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
4. The first start takes about 2 minutes. It also puts an **XMage Playgroup** icon on your desktop.

## Play

- **Play vs AI**: a game against the computer, on your own PC.
- **Create Room** / **Find Game on XMage**: play with friends on the XMage server
  (default `beta.xmage.today`). Everyone in the group uses the same server.
- Set your player name in Settings (click your name, top right).

Close the game window to stop. The game tells you when a new version is out.
